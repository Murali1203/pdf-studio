# PDF Studio acceptance checklist

Use harmless sample PDFs only. Do not tick an item until you have performed it in the browser.

## Fast submission test

- [ ] With Wi-Fi off, load a harmless PDF and use Organise, Edit, Stamp, Convert and Finish controls.
- [ ] Export an organised PDF and open it in another PDF reader.
- [ ] Confirm before/after size is shown after export.
- [ ] Add a secure redaction, export, then search the exported PDF for the redacted word. It must not be found.
- [ ] Test image-to-PDF, PDF-to-text and PDF-to-image using safe files.
- [ ] Compare two PDFs locally.

## Full-project rubric

- [ ] Edit a 50-page PDF offline using tools from all five groups.
- [ ] Saved output opens in another PDF reader.
- [ ] Redacted text cannot be selected or found by search.
- [ ] Compression displays the file size before and after.

## Known test focus

- [ ] Test a real fillable PDF field before presenting form filling as complete.
- [ ] Check that multiple PNG downloads are allowed by the chosen browser.
- [ ] Check secure redaction output on a second PDF reader.
